# Docket verified listings

The Friday digest is built ONLY from rows here. A row may be added only when the automated check read the funder's official page in that run and it showed: status OPEN, an explicit deadline date in the future, and US eligibility text. Rows are removed or flagged when a later check no longer shows that.

Nothing in the table below is a guess. Empty means nothing is verified yet.

## Rules
- Never fill a cell from memory, from Docket's sample, or from a search snippet. Blank or "not stated on page" is correct if the page does not say.
- "Human confirmed" stays blank until the user confirms the row by hand. Digest drafts mark unconfirmed rows "AWAITING CONFIRMATION" and the user must confirm before anything is sent.
- Nothing is ever emailed or published automatically.
